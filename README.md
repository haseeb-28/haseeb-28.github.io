# Portfolio — Software Engineer version

## Structure
```
portfolio-se/
├── index.html
├── css/style.css
├── js/script.js  (mobile nav toggle only, no animation)
└── assets/
    ├── profile.jpg   ← add if you want a photo (not required by this design)
    ├── resume.pdf    ← required, resume download button links here
    └── favicon.png
```

## What changed from the animated version
- Positioning: "Software Engineer" (Flutter / Full-Stack / AI/ML) instead of "Full Stack Web & App Developer"
- No animations: no scroll reveals, no loops, no magnetic cursor, no marquee
- Tech list restricted to the approved skill set — React, Next.js, TypeScript, and Tailwind are not shown anywhere
- Contact section uses direct GitHub / LinkedIn / mailto links, no JS-driven contact form
- SmartMeds is included and explicitly labeled "In Progress · Unreleased"

## Projects intentionally left out of this version
**SpendWise and Resume Forge are not included.** Both are built primarily with React, Next.js, and Tailwind, none of which are on the approved tech list for this version. Showing them without their real stack would misrepresent what they're built with, and showing them with their real stack would break the restricted list. If you want them back in, the tech restriction needs to be dropped for those two entries specifically.

## Deploy
Same as before: push the folder contents to your GitHub Pages repo root. No build step.
